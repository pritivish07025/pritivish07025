# 🚀 Featured Project

## 🏥 HealthStock AI

### AI-Powered Healthcare Supply Chain Management Platform

**HealthStock AI** is an AI-powered healthcare resource and supply-chain management platform designed to improve visibility, forecasting, and decision-making across healthcare networks.

## 📌 Problem Statement

Healthcare systems in developing nations face supply-chain challenges across large networks of **Primary Health Centres (PHCs)**.

Lack of real-time visibility into medicines, beds, personnel, and resource utilization can result in:

- 💊 Medicine stock-outs
- 📉 Poor resource allocation
- 🚨 Reduced emergency response capabilities
- 🔄 Inefficient resource distribution
- 📊 Limited healthcare resource visibility

---

## 🎯 Challenge

Build a **federated AI platform for national-scale healthcare resource and supply-chain management**.

The platform should provide:

- 📦 Real-time medicine stock visibility
- 🛏️ Bed availability tracking
- 👨‍⚕️ Medical personnel attendance monitoring
- 📈 Demand forecasting
- ⚠️ Early warnings for potential stock-outs
- 🔄 Automated cross-district resource redistribution recommendations
- 🧠 Shared predictive modelling capabilities across BRICS nations

---

# ✨ Key Features

### 📦 Medicine Inventory

- Real-time medicine stock monitoring
- District-wise inventory tracking
- Medicine-wise stock visibility
- Daily demand monitoring
- Days-of-cover calculation
- Stock-out risk identification

### ⚠️ Stock-Out Risk Monitoring

The system analyzes medicine stock and demand patterns to identify potential shortages.

Risk levels include:

- 🟢 Low
- 🟡 Medium
- 🟠 High
- 🔴 Critical

### 🛏️ Bed Availability

- Facility-wise bed tracking
- Occupied bed monitoring
- Available bed calculation
- Current capacity visualization

### 👨‍⚕️ Personnel Monitoring

- Personnel attendance tracking
- Role information
- Facility association
- Check-in status

### 🔄 Cross-District Redistribution

The platform provides resource redistribution recommendations based on:

- Current stock
- Demand
- Shortage risk
- Available donor stock

### 🤖 AI Healthcare Copilot

The platform includes an AI-powered chatbot using the **Google Gemini API**.

Users can ask questions such as:

- Which medicines need action today?
- Where should we redistribute stock?
- Summarize emergency capacity.

### 🧠 Federated AI

The project demonstrates a privacy-aware federated AI architecture where participating districts can share aggregate model statistics instead of directly centralizing raw operational records.

### 📊 Data Visualization

Interactive charts are used to visualize:

- Medicine demand
- Stock trends
- Facility capacity
- Bed utilization
- Forecast data
- Healthcare resource indicators
